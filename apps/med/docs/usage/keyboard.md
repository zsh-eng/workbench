# Keyboard shortcuts

Press `?` for the shortcuts of where you are: Review, Commit, File, Editor, or
Pickers.
Type to search every context by action or key, such as `close`, `zz`, or `⌘K`;
Enter runs a row that has a command. On Linux, use Ctrl for ⌘, Alt for ⌥, and Ctrl+Alt for ⌘⌃.

| Action                                 | Shortcut                     |
| -------------------------------------- | ---------------------------- |
| Command palette                        | `⌘K`                         |
| Find a file                            | `⌘⇧K`                        |
| Search file contents                   | `⌘⇧F`                        |
| Find in the diff or a file             | `⌘F`                         |
| Find in a file, in Vim                 | `/` / `?`                    |
| Find's case / whole word / expression  | `⌥C` `⌥W` `⌥R`               |
| Open a repository                      | `⌘O`                         |
| Symbols in this file                   | `⌘⇧O`                        |
| Open a branch or worktree              | `⌘⇧G`                        |
| Open tab 1–9                           | `⌘1`–`⌘9`                    |
| Next tab that needs you, or new        | `⌘0`                         |
| Close tab / reopen closed tab          | `⌘⌥W` / `⌘⌥T`                |
| Move the focused tab                   | `⌥↑` / `⌥↓`                  |
| Switch, or search archived threads     | `⌃Tab`                       |
| Toggle the sidebar / review            | `⌘B` / `⌘⇧B`                 |
| Toggle a page's sidebar / session rail | `⌘⌥B` / `⌘⌥⇧B`               |
| Next permission mode (message)         | `⇧Tab`                       |
| New thread (`⌘N` in the installed app) | `⌥N` or `⌘N`                 |
| Focus the next pane                    | `⌘⌥←`                        |
| Move the focused pane                  | `⌘⌥⇧←`                       |
| Expand the review (or session in use)  | `⌘E`                         |
| Balance the panes                      | `⌘⌃=`                        |
| Review / Changes / Commit / Files page | `1` / `2` / `3` / `4`        |
| Back / Forward                         | `⌃-` / `⌃⇧-`, or `⌘[` / `⌘]` |
| Comment on selected lines              | `c`                          |
| Comment on a file's lines, in Vim      | `gc`                         |
| A name's definition, in Vim            | `K`                          |
| Next / previous guide segment          | `j` / `k`                    |
| Next / previous excerpt or reply       | `]` / `[`                    |
| Next / previous prompt, in the thread  | `}` / `{`                    |
| Resume search                          | `⌥R`                         |
| Show tab 1–8 / the last tab            | `⌥1`–`⌥9`                    |
| Previous / next tab                    | `⌘⇧[` / `⌘⇧]`                |
| Toggle gutter blame                    | `⌥B`                         |
| Close the file or Search               | `⌥W`                         |
| Close all files in the workspace       | `⌥⇧W`                        |
| Close other files                      | `⌥⇧O`                        |

In a thread, `⌘O` and `⌘⇧G` show the repository, branch, or worktree inside
the thread; `⌘↵` in the picker opens a new workspace.

Close actions keep the Changes tab and other workspaces. Tab numbers count the
Review, Changes, Commit, and Search tabs with the file tabs. A browser can take some
shortcuts first; the command palette has the same actions.

## Commit page

Press `q` to open or leave the Commit page
([Commit and push](edit-files.md#commit-and-push)). Its keys work while the
focus is not in a text field.

| Action                                     | Shortcut            |
| ------------------------------------------ | ------------------- |
| Next / previous file, or hunk in its hunks | `j` / `k`           |
| Stage or unstage the file or hunk          | `Space`             |
| Go into the file's hunks / back to files   | `Enter` / `Esc`     |
| Discard the file or hunk, after asking     | `d`, then `d` again |
| Discard only unstaged changes, after `d`   | `u`                 |
| Stage or unstage every file shown          | `a`                 |
| Open the file                              | `o`                 |
| Filter the files                           | `/`                 |
| Write the commit message / commit          | `c` / `⌘↵`          |
| Push the branch                            | `⇧P`                |
| The page's keys                            | `?`                 |
