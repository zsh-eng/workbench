# Paper Mono

Source: https://github.com/paper-design/paper-mono/tree/e6eaeceaef02e77e3db997711e07a16378de2bd7 (`fonts/webfonts/PaperMono[wght].woff2`)

Self-hosted variable WOFF2 file for Paper Mono by [Paper](https://paper.design/mono), the code font. Its weight axis runs from 100 to 800. Paper Mono is based on Geist Mono. Font software is licensed under SIL OFL 1.1; see PAPER-MONO-OFL.txt. No font package or remote font request is required at runtime.
