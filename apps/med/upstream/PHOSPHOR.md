# Phosphor icons

Source: `@phosphor-icons/core` 2.1.1, `assets/regular`
(https://github.com/phosphor-icons/core). MIT License; see PHOSPHOR-LICENSE.txt.

Med's icons in `src/web/components/Icon.tsx` are this set's regular weight,
copied as path data, so Med has no icon package at runtime. Each Med name
notes the Phosphor icon it uses.
