One window for the whole review. From the agent's guide to the pushed commit.

Review

Read the agent's guide

The agent hands over its work with a guide: a summary that cites the lines it changed, then the change in small segments that you check one at a time.

  • The checks it ran, and what they miss
  • Its notes on the lines that need care
  • Diagrams, tables, and images in place

Changes

Comment on the diff

Commits and working changes read as one continuous diff, split or unified. Comment on a line or a range without leaving the keyboard.

  • Blame for the line at the cursor
  • Find any file, code, or symbol
  • Vim keys in the editor

Session

Work with your agents

Each task is a thread, with the agent's session as its main view and the review beside it. Send your comments from the message box, and the next hand-off shows what is new since you looked.

  • Start Claude Code or Codex from any review
  • See which agent needs you
  • Allow or deny each request

Commit

Commit, push, and follow the pull request

Stage files, write the message, commit, and push from the Commit page. Pull requests that wait on you are one list, and each opens in its own worktree, with its checks, reviews, and comments from GitHub.

  • Med never force-pushes
  • Codex review findings as comments
  • GitHub through your own gh sign-in

Notes

Keep your notes beside the code

Add an Obsidian vault next to your repositories. Notes open as they read; follow wiki links and backlinks, and press ⌘⇧V to edit the source in Vim.

  • Markdown, math, and Mermaid
  • Image embeds with sizes
  • Your .obsidian settings stay as they are

  • Runs on your machine

    One executable with the UI and offline docs. No account and no cloud.

  • Keyboard first

    c comments on the line, q opens the Commit page, and ⌘K finds every command.

  • Open source

    MIT licensed. Saved reviews keep their code and comments across restarts.
