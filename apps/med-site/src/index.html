What Med does

  • Runs on your machine

    Med is a local server that you use in your browser. It sends nothing to any server.

  • Review links from agents

    An agent runs med review create and gives you a link. Its brief cites the changed lines.

  • One review per task

    Later rounds of the same task become iterations of one review. Earlier briefs and comments stay.

  • Comments go back

    Comment on a line or a range. Copy comments gives you Markdown to paste into the agent.

  • One continuous diff

    Read commits and working changes as one split or unified diff, with history, files, search, and themes.

  • One executable

    The download includes Bun, the browser UI, and offline docs. You do not need to install Node or Bun.
