## 1. The web has no text, the phone keeps the article

Rule broken: Once the phone has an article's text and is done syncing, the web can show it too.
In the model, one step leads into this bug: "The phone keeps a Reader copy".

0. Start: The web has no text, the link is not on the phone yet
1. The phone gets the link. Now: The web has no text, the phone has no text
2. The phone keeps a Reader copy. Now: The web has no text, the phone keeps the article

With the fix you see the same states and steps, yet the rule holds, so the state labels do not show what the fix changes.
